# 代理提交

提交说明格式：`<new|mod|del>: [<范围>] <说明>`

| 动作 | 含义 |
|---|---|
| `new` | 新增 |
| `mod` | 修改 |
| `del` | 删除 |

| 范围 | 内容 |
|---|---|
| `skill` | Skill 及其实现、验证用例 |
| `tool` | 工具及其实现、测试 |
| `docs` | README 和项目文档 |
| `rules` | `CLAUDE.md` 和代理规则 |
| `ci/cd` | 持续集成与部署配置 |

一次提交只写一个范围，说明使用英文，写清变更目的。同一功能的实现、测试、必要文档和索引更新作为一个整体提交；无关功能和规则变更分批提交。

例：`mod: [skill] change asr model`

## 提交前检查

- 按变更范围完成测试与验收，发布要求见[更新与发布规则](rules-of-publish.md)
- 执行 `git log -10 --format='%s'; git status --short`，确认近期提交语言、风格及工作区状态
- 执行 `git diff --check`，审查变更与暂存内容
- 不提交凭据、本地配置、缓存、临时产物和无关文件
- 仅在用户明确要求时提交；禁止推送和发布
