三步启动本地入口

上游可使用任意 OpenAI 兼容服务

npm install -g mock-ollama export MOCK_OLLAMA_BASE_URL="https://api.example.com/v1" export MOCK_OLLAMA_API_KEY="your-api-key" mock-ollama --open

不改客户端，换上游

兼容层留在本机，真实密钥只交给 mock-ollama

03 · UPSTREAM

真实模型服务

转发到 Chat Completions、Anthropic Messages 或 OpenAI Responses 上游

三种客户端协议

同格式直接透传，不同格式以 --bridge 自动转换

Chat Completions适配 Cursor、OpenAI 兼容 SDK 和现有脚本/v1/chat/completions
Anthropic Messages适配 Claude Code 与 Anthropic 协议客户端/v1/messages
OpenAI Responses适配 Codex 与 GPT-5.6 系列客户端/v1/responses

需要跨协议？开启 bridge

当客户端与上游格式不一致时，开启三协议 3×3 矩阵互转。文本、SSE、工具调用、system 消息和 reasoning 都在桥接范围内

  • Claude Code → Responses 上游
  • Codex / GPT-5.6 → Anthropic 上游
  • Cursor → 任意兼容上游
mock-ollama \ --url "https://api.example.com/v1" \ --apikey "your-api-key" \ --api-style responses \ --bridge

连接 Claude Code

通过 Anthropic Messages 路由连接本地 mock-ollama

olm_claude() { local model="${1:-gpt-5.6-sol}" # 设置默认模型 shift ANTHROPIC_AUTH_TOKEN=ollama \ ANTHROPIC_BASE_URL=http://localhost:11434 \ CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 \ ANTHROPIC_MODEL="$model" \ ANTHROPIC_DEFAULT_SONNET_MODEL="$model" \ ANTHROPIC_DEFAULT_OPUS_MODEL="$model" \ ANTHROPIC_DEFAULT_HAIKU_MODEL="$model" \ ENABLE_TOOL_SEARCH=false \ claude --permission-mode acceptEdits --model "$model" "$@" } olm_claude

Cursor BYOK 的安全公网入口

主服务保持本机监听，不直接暴露管理和监控接口

# 主服务运行后，另起 Cursor 最小入口 mock-ollama --cursor

安全设计：Cursor 入口只公开 /healthz、/v1/models 与 /v1/chat/completions，除健康检查外均需要 Bearer 认证。临时 Tunnel 重启后地址会变化，长期使用请配置受控域名和 Cloudflare Access
