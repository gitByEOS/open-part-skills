# teach-my-child

把原题和变式做成纯 HTML、离线可播的讲解页。换题只改数据，版式不要改。

每一步必须同时做到两件事：

> 状态 → 一步操作 → 可打印的新状态
> 下一步必须接得上上一步，过渡播完即停。淡入、滑入、翻转都可以。换景可以，但必须有过渡，不要无故整页替换

衔接是步进过渡，不是循环表演。到位后只留模板那一下极弱呼吸，lesson 不要再加晃动。

接到题目就必须做成讲解页：要有原题，再给一道同类变式。对象是 15 岁以下的孩子。题干、步骤、原理用短句，能口算就口算。禁止方程组、设未知数、矩阵、进阶公式。

打包：`python3 scripts/build.py <课.lesson.js> -o <出.html>`。无 `-o` 会写到课文件旁边；换目录或发布验证必须带 `-o`。只读本 Skill 模板与指定 lesson.js，写入指定 HTML；不访问网络。输出单文件，`file://` 可打开。

## 读这些文件

按这个顺序读，不要对着空气写 `run`：

| 顺序 | 文件 | 读它做什么 |
|---|---|---|

| 2 | [references/lesson.schema.js](references/lesson.schema.js) | 对照字段 |
| 3 | [assets/template.html](assets/template.html) | 版式不要改；引擎 helper 在脚本顶部 |

## 写课时

顶部三个标签文案固定：原题讲解 / 触类旁通 / 原理巩固。`questions[0]` 原题，`questions[1]` 变式。原理巩固：上方虚框、下方打乱的卡，点卡入框、点框回落。`points` 书写顺序就是正确答案。错了红叉抖动后重置，对了左右下角喷粒子。

`run` / `reset` 必须用 `$(sel, viz)`。`reveal` / `conceal` / `moveTo` / `nudge` 是捷径，不是上限。更丰富的表现写在本题 `style` 和 `run` 里：翻转、缩放、换景都可以，一次性播完即停。不要改模板，不要循环晃。讲解页左右方向键等于上一步 / 下一步。

原理篇在原题讲解和触类旁通上必须同一套字。`points` 从上到下就是卡牌顺序。`theorem` 禁止顺序词：先、然后、最后、首先、其次、接着。`change` / `why` / `formula` / `read` 用短句，不要术语堆砌。

页面块不要增删改名：题目描述 → 动画区 → 变化描述 → 变化讲解 → 圆点与播放按钮 → 原理篇。原理巩固页会暂时收起三区和原理篇。

## 生成步骤

1. 复制 `references/area.lesson.js` 再改，不会写 `run` / `reset` 就对着示例改。
2. 抽出 3~4 条原理，每条一句共用解读，两道题都能对上。写成孩子能读的短句。
3. 按「哪个量从 A 变成 B」拆步，步数随题；写不出变化量就换拆法，不要为凑步数合并或跳步。
4. `diff` 全部字面量，禁止在 `run()` 里算数。
5. `build()` 只建 DOM；挂到 `#viz` 之后才由播放器调 `reset()`。
6. 每步 `run()` 只做一次到位。代数合并可以没有 `run`。到位后不要再抖。
7. 人、物用带字色块，不要 emoji，不要生僻符。
8. 用 `scripts/build.py` 打包，换目录加 `-o`，按下表做交付前自检。

## 硬约束

| 坑 | 正确做法 |
|---|---|
| 回退/跳步后数字乱 | `run` 按「从 reset 之后逐步叠加」来写，引擎会 `reset` 后重放 `0..i` |
| 「下一步」图瞬切 | 引擎正向只跑新一步；用一次播完就停的过渡，不要瞬间换 innerHTML |
| 到位后还在晃 | 衔接一次就停。循环动画由 `build.py` 拒收；待机呼吸已在模板里 |
| 下一步接不上 | 步进要衔接；换景必须过渡，不要无故整页替换 |
| 点瞬移 | 用 CSS `transform` 或一次性 animation；禁止改 `cx` / `cy` / `x` / `y` / `points` / `d` |
| 构造时 `reset()` 报 null | `build()` 只建 DOM，不要自己先 `reset` |
| SVG 改 class 无效 | 用 `setAttribute('class', …)`，不要改 `className` |
| CSS 压住显隐 | 用 `conceal` / `reveal`，不要只改 SVG 的 opacity 属性 |
| 外部依赖 | 纯内联 CSS/JS，不引 CDN |
| 解法太难 | 只用口算和加减乘除；禁止方程组、设未知数 |
| 原理卡泄漏顺序 | `theorem` 不要写先 / 然后 / 最后 / 首先 / 其次 / 接着；`build.py` 会拒收 |

## 交付前自检

做完讲解页、交给孩子看之前勾完。不是改本 Skill 用的。

- [ ] 文案给 15 岁以下能看懂；解题只用口算和加减乘除
- [ ] 切题只换题干和动画，两页原理篇一字不差
- [ ] 每题点「下一步」能走到最后，数字对，图有一次过渡后停住
- [ ] 下一步接得上上一步；换景有过渡，没有无故整页替换
- [ ] 顶部是 原题讲解 / 触类旁通 / 原理巩固
- [ ] 原理巩固：卡能放进虚框、能拿回来；错了重置，对了喷粒子
- [ ] 原理卡没有「先 / 然后 / 最后」
