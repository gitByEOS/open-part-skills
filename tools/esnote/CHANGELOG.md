# 更新日志

### 新增

- `⌘J` 可插入单行任务条
- 终端可调缓冲行数

### 改进

- 终端体验优化、性能优化

### 修复

- 外部文件冲突改为可拖动浮动面板，不再卡住编辑区

### 新增

- 支持 `YAML` 表头预览
- 支持 README 徽章、原始 HTML

### 修复

- 带跳转徽章或本地图片
- 单独打开 Markdown 时相对路径图片未正常显示

## 0.2.1 — 2026-08-18

### 修改

- 大文件性能优化
- 多轮完善测试集


## 0.2.0 — 2026-08-18

### 新增

- 右侧终端（`⌘'`）：再按只收起；聚焦时 `⌘K` 清屏；按住 `⌘` 可点输出里的 `.md` 打开
- 工作区查找（`⇧⌘F`）：搜 Markdown，点结果跳行
- 多窗口：已打开文件夹时再开目录会新开一扇。`esnote -n` 空窗，`-r` 才换当前文件夹
- 文件树右键新建 / 重命名 / 移动 / 删除；工作区文件变化会自动刷新
- `⌘↩` / `⇧⌘↩` 在当前行下 / 上方新建空行，不拆开这一行
- 无选区 `⌘X` 剪切整行
- `⌘J` 可插入任务卡、代码围栏；`+` 列表回车会继续
- 开发者模式（`⇧⌘2`）：沉浸布局但留下终端

### 修复

- 输入时正文不再整页跳一下
- 缩进的撤销 / 重做恢复正常
- 有序列表中间增删后会自动重编号
