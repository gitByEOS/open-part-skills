把 QBot 跑起来

从 npm 安装到 QQ 收到第一条回复，共 12 步，每步都很短

1

确认你的 Mac 准备好了

需要 Node.js 22.5 或更高版本，打开「终端」检查：

node --version
看到 v22.5.x 或更高就过关。低于 22.5 先去 nodejs.org 装新版。
2

全局安装 qbot

一条命令装好 qbot 命令行工具：

npm install -g @eos./qbot
看到 安装完成、无红色报错就行。卡住可换 sudo 或配 npm prefix。
3

安装并登录 Codex CLI

QBot 让 Codex 干活，先装好 Codex 并登录。两行依次执行：

npm install -g @openai/codex codex login
看到 登录成功提示即可。已装过可跳过，用 codex login status 确认。
4

验证 qbot 可用

装完重开一个终端，确认命令能找到：

qbot --version qbot --help
看到 版本号和帮助文字就 OK。

若提示 command not found，把 $(npm config get prefix)/bin 加进 PATH 后重开终端。

5

打开 QBot 控制台

控制台是首次配置主入口，会自动建好配置目录和文件：

qbot dashboard
看到 浏览器自动打开控制台。没自动开就手动访问终端打印的本地地址。
6

填写机器人凭据

通过「扫码接入」获取你的专属凭据，填入「配置」这两项，然后点击右上角保存配置：

QQ_APP_ID = 你的 AppID QQ_APP_SECRET = 你的 AppSecret
看到 保存成功即可。白名单先留空，下一步启动后拉取你的 OpenID。
7

启动服务并拉取 OpenID

启动网关后用你的 QQ 给机器人发条消息，再到控制台拉取你的 OpenID：

qbot start

用任意 QQ 号给机器人发条消息，在自动获取区域，依次点击 拉取 → 采用 → 测试：

收到 QQ 消息即证明配置成功。

私聊用 user_openid，群聊用 member_openid，都不是 QQ 号。

8

重启网关使白名单生效

在运行 qbot start 的终端按 Ctrl+C 停止，再重新启动让白名单生效：

qbot start
看到 一串启动日志、没立刻退出就行。下一步看关键标志。
9

看到 READY 就成功了

在启动日志里找这一行，出现就代表 QQ 网关已就绪：

QQ bot is online (READY)
看到 这行就部署完成。没出现就检查 AppID/AppSecret 和网络，或跑 qbot doctor 体检。
10

在 QQ 里发条消息

用白名单里的账号给机器人发这条消息试试：

五分钟后提醒我喝水
看到 机器人回复确认就部署成功 🎉。到点会自动私聊提醒你。

常用命令：/reset 清上下文、/new <任务> 开新会话、/stop 中断任务。

11

配置项目路径

想让机器人在指定项目里读写代码，在控制台「配置设置」里填项目根目录，改完点右上角「保存配置」：

QQ_PROJECT_ROOT = /Users/你/Projects

保存后自动热加载，无需重启网关。在 QQ 里就能用这些命令切换项目：

/dir 列出项目 /dir 2 切换到第 2 个 /dir new demo 新建名为 demo 的项目
看到 机器人回复项目列表就生效。每个项目独立上下文，切回会恢复原对话。

项目目录不是安全沙箱，所有白名单用户都能让 Codex 读写所选项目，只配可信用户。

qbot dashboard
