如何使用

引入 codicon.css 后，用类名即可显示 VS Code 图标字体

下载资源

将字体与样式放在同一目录，或自行调整 CSS 中的字体路径

下载 TTF 下载 CSS

1. 引入样式

<link rel="stylesheet" href="codicon.css">

2. 基础用法

<i class="codicon codicon-add"></i>
<i class="codicon codicon-search"></i>
<i class="codicon codicon-settings-gear"></i>
add search settings-gear

3. 调整大小与颜色

<i class="codicon codicon-heart" style="color:#ef4444"></i>

图标本质是字体，直接改 font-size 和 color 即可

4. 放在按钮里

<button class="demo-btn">
  <i class="codicon codicon-save"></i>
  保存
</button>

5. 查找图标名

在本页搜索并点击图标，即可复制对应 HTML 代码
