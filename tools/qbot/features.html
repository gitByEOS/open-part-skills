功能模块能力说明
01多机器人实例
  • qbot new <name> 创建命名实例，独立保存 QQ 凭据、会话、附件、待办、角色设定和工作区
  • 每个实例独立分配浏览器抓取、管理台和常驻网页服务端口；实际分配记录在 app_config.json
  • qbot start|dashboard|doctor <name> 操作指定实例；默认无名称命令保持原有单实例行为
  • Codex 登录态与 $CODEX_HOME 是机器级共享状态，不属于实例隔离范围
02对话与上下文
  • 私聊延续上下文，群聊/频道共享上下文，消息排队处理
  • /new /reset 清除当前上下文；/new ter/sol/luna <任务> 指定模型
  • /rotate 触发 gateway 层轮换压缩：生成交接摘要并切换新 session，ctx 归零；可单独发，也可 /rotate 继续做X
  • /stop /cancel 中断当前及排队任务
  • 上下文超 70% 自动轮换，生成交接摘要续接新会话
03定时提醒
  • 直接说要提醒的事和时间，Agent 登记后立即回复，到点自动私聊推送
  • 支持"提醒我 1 小时后喝水"等单次提醒，以及带 IANA 时区的 cron 周期提醒
  • 可查询、完成、取消待办
  • 网关重启后历史逾期待办一次性补推
04项目目录

配置 QQ_PROJECT_ROOT 后：

  • /dir 列出项目，/dir N 切换，/dir new <名称> 创建新项目
  • 每个项目独立上下文，切回恢复原状
  • 运行时产物（日志、服务）隔离到独立目录，不污染所选项目
05权限管理
  • Dashboard "Git 写操作"开关，默认关闭，热加载生效
  • 开启后 Agent 可写 Git 元数据（暂存、提交），支持普通 clone 与 linked worktree
06附件
  • 可发图片、文本、代码、JSON/CSV/PDF 等文档
  • 先发附件再在 10 分钟内发文字即可配对
  • 压缩包和可执行文件会被拒绝
07文件回传
  • 用自然语言要求"把报告发给我"，Agent 生成文件后通过 QQ 回传
  • 文件须在当前工作区内
08角色设定
  • 首次对话注入 soul.md，后续不重复
  • 修改后下次对话自动注入新版本
09常驻网页服务
  • 要求"做一个局域网网页，启动后把地址发给我"，Agent 托管服务并回复真实地址
  • 服务跨回合存活，可自然语言查询或停止
10网页截图与浏览器操作
  • 截图网页得 PNG 路径，用 <qqmedia> 回传 QQ；产物写入会话隔离目录（$QQ_ISOLATION_ROOT），路径校验防逃逸
  • 单纯截图用只读 screenshot；需交互、等待或操作后状态时用 actions
  • actions 一次请求内可串联打开、填表、点击、条件等待、截图与取数
  • 可提取正文、元素文本、表格（JSON），或在页面执行 JavaScript 取数
  • target 优先稳定选择器（id/name/aria/label/testid/role+name/文本/CSS）
11流式回复
  • 默认私聊实时更新回复
  • exec 模式额外显示命令和文件修改进度
  • 可关闭流式或 Markdown 适配客户端
12安全
  • 仅 QQ_ALLOWED_SENDERS 内的发送者可用
  • 项目目录拒绝符号链接逃逸
  • 运行时文件权限 0600，不公开提交
13软件更新
  • Dashboard 更新页查询 npm，展示逐版变更，不自动下载或安装
  • package.json 的 qbot.releaseNotes 记录每版说明
  • 本地版本领先 npm 时明确提示，不误报"已是最新"
  • 默认机器人每 5 天检查一次，有新版本向白名单私聊推送升级命令
